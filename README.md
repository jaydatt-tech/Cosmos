# COSMOS — Explore the Universe

B.Tech semester web development project built with HTML, CSS and JavaScript.

## Current stage
This starter contains the complete responsive homepage and shared JavaScript interactions. The remaining 29 pages will be developed in later stages.

## Run the homepage
1. Extract the ZIP file.
2. Open the `COSMOS` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Try the mobile menu, Cosmic Fact button, and topic search.

## Current homepage interactions
- Responsive mobile navigation.
- Rotating cosmic facts.
- Topic search that routes to the relevant planned page when it is created.
- Animated CSS solar-system preview.
- Responsive layout and reduced-motion support.

## Planned project modules
- Home and discovery
- Solar system (2D and 3D)
- Planets and moons
- Deep space
- NASA and ISRO missions
- Astronomy quiz
- Planetary weight and age calculators
- Space image gallery
- Astronomy glossary

## Important
The homepage navigation includes links to pages that are planned but not included yet. They will become active as those pages are developed. The 3D solar system will be implemented in a later stage using Three.js.
